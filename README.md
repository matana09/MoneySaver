# 💰 MoneySaver

אפליקציית ניהול הוצאות חודשיות **לוקאלית**.
הנתונים נשמרים מקומית. תכונות AI אופציונליות שולחות הקשר לספק שנבחר;
הבוט מתקשר דרך טלגרם. אין שמירת סיסמאות בנק או ביצוע פעולות פיננסיות.

## הרצה

```bash
npm install
npm start
```

- **מקומי:** http://localhost:3000
- **גישה מרחוק:** חסומה כברירת מחדל. הפעלה מחייבת סיסמה ו-HTTPS דרך proxy מקומי;
  ראו `SECURITY.md` ו-`deploy/Caddyfile.example`. אין לחשוף את פורט 3000 לרשת.

דרישות: Node.js 22.5+ (ל-SQLite מובנה). אופציונלי: Python 3 + `pip install scikit-learn` למנוע החיזוי — בלעדיו המערכת עובדת עם חוקים והיסטוריה בלבד.

## יכולות

| יכולת | איך |
|-------|-----|
| **"כמה נשאר להוציא החודש"** | מחוון מרכזי בדשבורד, מתעדכן עם כל עסקה |
| **ייבוא מהבנק/אשראי** | עמוד "ייבוא" — קובץ CSV/PDF (Isracard, Cal, Max, לאומי…), זיהוי עמודות אוטומטי, תצוגה מקדימה, סינון כפילויות |
| **קליטת SMS** | הדבקה בעמוד הייבוא או העברה לבוט הטלגרם |
| **קטגוריזציה אוטומטית** | היברידי: חוקים (regex) → היסטוריה → מודל ML שלומד ממך |
| **חיזוי סוף חודש** | עקומת הוצאה מצטברת מחודשים קודמים (scikit-learn) עם fallback |
| **בוט טלגרם** | "קפה גרג 25" מכל מקום, קבצים, SMS, "מצב" — והתראות תזרים א'/ג'/ה' |

## חיבור בוט טלגרם

1. פתח את **@BotFather** בטלגרם → `/newbot` → העתק את ה-token
2. הדבק את ה-token בעמוד **הגדרות** → שמור
3. שלח `/start` לבוט שיצרת — נרשמת להתראות

## מבנה

```
server/          Express + SQLite (node:sqlite)
  routes/        API: transactions, flow, import, forecast…
  lib/           פרסרים (CSV/PDF/SMS), קטגוריזציה, לקוח ML
  bot.js         בוט טלגרם (grammY) + התראות
ml/service.py    scikit-learn: סיווג + חיזוי (child process)
public/          SPA — 7 עמודים, RTL, Chart.js
data/            moneysaver.db — גבה את הקובץ הזה!
```

## אבטחה ופרטיות

- אין חיבור Open Banking, אין scraping, אין שמירת סיסמאות בנק
- הנתונים נשמרים ב-`data/moneysaver.db`, כולל מפתחות וסודות בהגדרות. הקובץ
  והגיבויים אינם מוצפנים על ידי האפליקציה: יש להגן עליהם בהרשאות מערכת
  ובאמצעות הצפנת הכונן והגיבויים.
- AI: ההקשר נשלח ל-Gemini או ל-Codex לפי ההגדרה. הסרת פרטים מזהים בקוד
  מצמצמת חשיפה אך אינה מבטיחה אנונימיות. סכומים והקשר פיננסי עדיין עשויים להישלח.
- טלגרם: הודעות וקבצים לבוט עוברים דרך תשתית טלגרם.
- קריאה בלבד: המערכת לא מבצעת שום פעולה פיננסית
- **הבוט נעול ל-owner:** רק ה-chat שביצע `/start` ראשון מקבל מענה; כל גורם זר נחסם
- הגנות קלט: ולידציית regex נגד ReDoS, גבול גודל body (256kb), cap אורך שדות,
  prepared statements (נגד SQLi), escaping בצד לקוח (נגד XSS)
- ממשק ה-web מוגבל לחיבורים מקומיים. אפשר להגדיר אימות גם מקומית ב-`.env`.
- פרסום קוד: `npm run export:github` יוצר עותק נפרד ב-`output/github-ready`
  עם היסטוריית Git חדשה וזהות פרויקט ללא כתובת אישית. אין לדחוף את ההיסטוריה
  של תיקיית העבודה המקורית. ראו `SECURITY.md`.

בדיקות: `npm test` בלבד — מסד זמני ושרת נפרד על פורט 3100.
תבניות Windows: `powershell -File scripts/configure-tasks.ps1` יוצר קובצי
UTF-16 LE מקומיים ב-`tmp/tasks`. הוספת `-Register` רושמת אותם במתזמן המשימות.
